# Student Management System

A full-stack Student Management System built using Flask and SQLite.

- User Authentication
- Student CRUD Operations
- Search Students
- Responsive UI
- SQLite Database

## Tech Stack

- Flask
- SQLite
- HTML
- CSS
- Bootstrap
